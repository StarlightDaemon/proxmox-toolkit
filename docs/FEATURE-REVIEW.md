## Findings fixed during implementation and final review

- Kept Enter dispatch in a build block unique to Paste & Execute. Paste Only
  accepts a terminal without input(), shares normalization/limits/cancellation,
  rechecks after preparation, calls paste once, and reports partial-send uncertainty.
- Separated extraction from writing. Export has no clipboard grant/API; diagnostics
  and recipes have no row extraction or terminal dispatch. All six individual
  boundaries are tested, including no extra network/download permission.
- Corrected missing-console installation availability: only Diagnostics stays
  available when a unique native anchor has no usable frame. Multiple native
  anchors still refuse integration. Report reason scenarios cover all 20 codes.
- Changed unobserved diagnostic counts from zero to null and refused nonprimitive
  native identities without coercion. Seeded secrets/IDs/URLs and arbitrary
  objects never enter the report; wrapped-frame inspection remains contained.
- Added owner-loss/navigation/teardown cancellation to clipboard-write tracking.
  Owner-only release survives replacement tokens; delayed callbacks cannot replace
  cancellation/timeout feedback. Already dispatched writes cannot be undone.
- Utility conflict markers are on Toolkit's Tools button as well as menu items;
  combinations suppress duplicate actions without exporting privileged functions.
  Fixed-rank insertion remains deterministic for six individuals in varied orders.
- Panel callbacks reject a changed top-page URL before an event/scan. Recipe copy
  separately compares the original frame/terminal/URL/native target, refuses LXC
  node-only selections and ambiguity, and never invokes terminal input.
- Removed repeated input discovery from the clipboard-busy presentation transition:
  one activation session resolution precedes reading. Idle/pending scans continue
  to share each resolved console across actions; asynchronous boundaries stay fresh.
- Native panel construction failure, recursive owner/menu destruction and navigation
  clear child components, feedback/watchdog timers and temporary download resources
  once. Late callbacks cannot revive a closed panel. No raw error text is displayed.
- Export uses Copy's exact extraction and UTF-8 bytes. Long backtick fences and
  HTML-like text survive literally. Anchor/URL cleanup covers success, allocation/
  append/click failures and teardown; feedback states download intent only.

No unresolved actionable source defect was identified in this local pass. The
native environment limitations below still require the prepared acceptance run.

## Evidence and remaining limits

- Real-xterm fixtures verify wrapped/wide Unicode buffers, alternate-screen
  selection and export bytes. Renderer-free paste emits data and then throws for
  its missing textarea; this proves partial-send/no-retry handling, not successful
  rendered paste or remote command execution.
- Mocked ExtJS/Firefox adapter tests prove the exercised contracts, not actual
  menu placement, keyboard/focus behavior, narrow-toolbar overflow, themes or
  manager compartment behavior. These are pending in Firefox + Violentmonkey.
- Object-URL request/cleanup tests do not prove a browser saved a file. Actual
  download cancellation, MIME/filename behavior and immediate-close timing need
  inspection in the target browser. No browser profiling was performed.
- Clipboard completion, unconfirmed dispatch and timeout are distinct. Permission
  prompts and actual clipboard contents need live observations. A late manager
  write may still change the clipboard after cancellation or timeout.
- Diagnostics are allowlisted snapshots, not permission guarantees. Recipes are
  reviewed static strings, not proof of tools, distribution, program or privilege.
  Source references and applicability limits are in [Usage](USAGE.md).
- CSS/session changes unobserved between event/polling boundaries cannot be
  reconstructed. Existing safeguards and the 500 ms policy are preserved.

Stable 0.5.0, earlier tags and historical evidence are unchanged. No commit,
remote update, PR, merge, release or publication occurred. The manual acceptance
campaign and any later publication remain separate authority/evidence boundaries.
